# Folder klip

Taruh klip video (`.mp4`) di folder ini, dengan nama berurutan supaya urutan gabungnya benar, misalnya:

```text
scene01.mp4
scene02.mp4
scene03.mp4
```

- Urutan gabung = urutan alfabet nama file.
- Masing-masing file maksimal 100 MB (batas unggah web GitHub).
- Format yang diharapkan: MP4 (h264 + AAC), vertikal 720x1280 atau 1080x1920. Workflow akan me-render ulang semuanya ke 1080x1920, 24 FPS.
