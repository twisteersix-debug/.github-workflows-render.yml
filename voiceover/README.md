# Folder voiceover

Taruh SATU file voiceover di sini dengan nama persis:

```text
voiceover.mp3
```

- Kalau file ini ada, audio klip diganti voiceover saat render.
- Kalau tidak ada, audio asli klip yang dipakai.
- Format: MP3. Durasi sebaiknya sama dengan total durasi semua klip (workflow memakai `-shortest`, jadi render berhenti di yang lebih pendek).
- File ini (README.md) hanya penanda supaya foldernya ada di repo.
